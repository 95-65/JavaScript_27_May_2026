# JavaScript_27_May_2026
🟢 var

var is a keyword used to declare a variable in JavaScript which is function-scoped, can be re-declared and re-assigned, and is hoisted with initial value undefined.

🟡 let

let is a keyword used to declare a variable in JavaScript which is block-scoped, cannot be re-declared in the same scope, but can be re-assigned, and is hoisted but not initialized (Temporal Dead Zone).

🔴 const

const is a keyword used to declare a variable in JavaScript which is block-scoped, cannot be re-declared or re-assigned, and must be initialized at the time of declaration.

Data Types
🟢 Primitive Data Types
1. String

A String is a data type used to represent text or sequence of characters enclosed in quotes.

2. Number

A Number is a data type used to represent numeric values including integers and decimals.

3. Boolean

A Boolean is a data type that can hold only two values: true or false.

4. Undefined

Undefined is a data type that represents a variable that has been declared but not assigned any value.

5. Null

Null is a data type that represents an intentional empty or no value.

6. Symbol

A Symbol is a unique and immutable primitive value used to create unique identifiers.

7. BigInt

BigInt is a data type used to store very large integers beyond the limit of Number type.

🟡 Non-Primitive (Reference) Data Types
1. Object

An Object is a data type used to store key-value pairs.

2. Array

An Array is a type of object used to store multiple values in a single variable in ordered form.

3. Function

A Function is a reusable block of code that is also treated as an object in JavaScript.
